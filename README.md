# 🚀 QuickDrop — Mac ⇄ Android Wi-Fi Sharing Platform

A fast, zero-install, local Wi-Fi data sharing solution between MacBook and Android devices.

---

## 🌟 Features

- **⚡ Zero Installation on Android**: Just point your Android camera at the QR code on the Mac screen.
- **📁 Bidirectional File Transfer**:
  - Drag and drop files on MacBook ➔ Instantly appears on Android.
  - Choose photos, videos, documents, or take photos directly on Android ➔ Automatically saves to Mac's `uploads/` folder.
- **📋 Real-time Clipboard Sync**: Share text, OTPs, links, passwords, and notes between Mac and Android with 1-tap "Copy".
- **🔍 File Previews**: View photos, play videos, and stream audio directly in the browser.
- **📂 Open in Finder**: One-click button on Mac to immediately reveal received files in Finder.
- **📶 Completely Local**: Works entirely over your Wi-Fi router or Mobile Hotspot — no cloud upload, private, and ultra-fast.

---

## 🚀 How to Run

### Method 1: Double-Click (Easiest)
Simply **double-click** `start.command` in this folder from macOS Finder. It will start the server and open the browser automatically.

### Method 2: From Terminal
```bash
npm start
```
Then open `http://localhost:3000` on your Mac.

---

## 📱 How to Connect Android Phone

1. Make sure **MacBook and Android are connected to the same Wi-Fi** (or Mac is connected to Android's Hotspot).
2. Look at the terminal output or the Mac web page — you will see a **QR Code**.
3. Open your Android phone's **Camera** or **Google Lens / QR Scanner** and scan the QR code.
4. Tap the link to open in your mobile browser (Chrome, Samsung Internet, etc.).
5. Start sharing files and text immediately!
